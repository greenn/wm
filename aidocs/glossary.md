# Короткий словарь

- **WM** — framework/resource base `J:\dv\wm`.
- **IQ** — site/project environment connector; не RM connector.
- **resource layer / r** — общая механика ресурсов; не один named RM.
- **named RM** — `rb`, `lay`, `site`, `admin`, project RM и другие.
- **component** — RM-каталог с `<component>.class.inc`.
- **template** — view внутри component/RM; не component сам по себе.
- **library connector** — `web/lib/<name>/<name>.php` + `_lib()`.
- **pages v2** — current server page data/resolution/handlers.
- **wd** — reference/live visual compare.
- **mqr** — optional JS runtime scaler по `[mqr]`, не media queries.
- **uv** — URL-version database под `site/uv`; `qv()` добавляет cache bust.
- **blank** — коммитируемая копируемая заготовка, не гарантия runtime.
- **dot-project** — reference project, точечно читаемый и исключённый из Git.
- **WebBuilder/wb** — planned placeholder без API; не legacy `w()/wb()`.
