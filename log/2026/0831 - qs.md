# Контрольные вопросы перед исходной базой

Дата: 2026-08-31.

Владелец подтвердил новую v2-схему страниц, разделение PHP-router и `vue-router`, два способа подключения `web`, исправленный IQ/router-контракт, канонический `/admin/index.php`, коммитируемые UV и автоматический push в `main`.

`wb` исправлен: в новых материалах это заглушка будущего WebBuilder app. Существующий legacy `w()/wb()` не описывает этот app и не должен подменять его смысл.

## Оставшийся файловый вопрос

Владелец сообщил, что добавил проектный RM `gss3`. Во время первой проверки загрузка ещё не была видна, но позднее в тот же день новый проект появился по правильному пути `.vmk4/gss3` и был проанализирован. Он содержит 21 RM-компонент с обязательными `<name>.class.inc`, новые pages, templates и project router. JSON с продуктами не открывались.

Анализ подтвердил архитектурную ценность примера и одновременно обнаружил технические следы незавершённого переноса: подключение общего `web`, контракт `selfDir/dirSelf`, CSS `%sid`, `routerFile`, путь custom-router и его context требуют отдельного исправления. Эти проблемы следует описать как известные, но не исправлять самовольно в рамках задания `=1`.

## Принятое безопасное решение по UV

Корневой `uv/` содержал старые копии файлов из `.vmk4/uv`, тогда как в `site/uv/` уже находились одноимённые более новые базы. Каноническим расположением принято `site/uv`; более новые файлы не перезаписываются.

## Принятое безопасное решение по settings

В разрешённых копиях `site/settings`, `.blank/.../settings` и `.blank2/site/settings` обнаружены project credentials и клиентские данные. Эти локальные конфиги исключаются из исходного Git-коммита; секретные значения не переносятся в документацию.
