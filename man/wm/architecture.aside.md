## Граница ответственности

```text
framework contract
  ├─ web runtime
  ├─ rb / lay
  └─ page + API mechanics

project contract
  ├─ iq + entry
  ├─ pages + router
  ├─ project RM
  └─ data + assets + tests
```

> [!TIP]
> Перед изменением найдите реальный entry, definition и consumer. Имя файла
> само по себе не подтверждает активную runtime-цепочку.
