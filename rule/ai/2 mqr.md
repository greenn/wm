# MQR

`mqr` — используемый не во всех проектах JavaScript runtime scaler. Это не
CSS media queries и не их замена.

Current-механизм:

- находит элементы с атрибутом `[mqr]`;
- при необходимости добавляет wrapper `.mqr-w`;
- вычисляет scale относительно заданной ширины/высоты;
- применяет `transform`/`transform-origin`;
- дополнительные атрибуты (`mqrc`, `mqrs`, `mqrw`, `mqrh` и другие)
  уточняют поведение.

Component находится в `r/rb/mqr`; provider имеет исторические варианты, и
точную подключаемую версию надо проверять у потребителя.

Использовать MQR только когда требуется масштабирование целого фиксированного
макета/виджета. Для обычной адаптивной вёрстки сначала применять CSS layout,
media/container queries. Проверять nested `[mqr]`, resize, transform origin,
кликабельные зоны, текст и отключённый JS.
