WM — карта большого задания

Проект: WM.
Базовая версия WM для этой серии работ: 20.0.1.
Каноническая ветвь архитектуры: v2.

Этапы

1. `=1.txt` — подготовить полный и исполняемый набор правил в `rule/ai`.
2. `=2.txt` — создать короткий agent-first `AGENTS.md` и структурированную карту
   `aidocs` для Codex.
3. `=3.txt` — создать автономный Documentation Site в `man` для владельца и
   разработчиков.
4. `=4.txt` — создать тестовый ресурсный модуль `blank/rm` и проверить страницу
   `blank/rm/index.php`.
5. `=5.txt` — создать соседний тестовый проект `J:\dv\wm-0` на базе правил v2.

Этапы выполняются последовательно. Каждый этап сначала использует результаты
предыдущего и не должен заново придумывать уже зафиксированные термины.

Общие критерии

- решения владельца имеют высший приоритет среди материалов проекта;
- `rule/dd` — концептуальный источник, `rule/ai` — нормализованная инструкция;
- существующий framework API исследуется и документируется, а не заменяется;
- новые имена соответствуют naming-правилам, legacy не переименовывается;
- каждый атомарный commit повышает PATCH;
- human-документация хранится в `man/wm`, agent-документация — в `aidocs`;
- сторонние улучшения сначала описываются в `man/sug` и требуют approval.
