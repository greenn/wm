# UV: URL versioning

`uv` хранит версии URL и используется для борьбы с browser/proxy caching.
`qv(<url>)` добавляет к URL вычисленную версию, сохраняя нужный query string.

Каноническое project/site расположение баз:

    site/uv/

Базы могут различаться по project/site и host. Они являются коммитируемой частью
текущего workflow, если владелец не указал иное. Старая дублирующая корневая
`uv/` не является новым каноническим местом.

Правила:

- asset URL пропускать через `qv()`, когда он участвует в uv;
- не добавлять произвольный timestamp на каждый request;
- не смешивать базы разных hosts/projects;
- после изменения generator/asset проверять новый query и фактическую загрузку;
- не править большое число записей без понятной причины;
- временные/backup-файлы не объявлять официальной базой;
- значения uv не являются версией WM или web.

При ошибке cache busting проверить подключённую DB, normalized URL, доступность
asset, тип выбранной версии и сохранение исходных query parameters.
