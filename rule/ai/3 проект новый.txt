# Новый проект

Первый целевой проект создаётся как соседний каталог J:\dv\wm-0, а не внутри WM. У него должен быть собственный AGENTS.md с локальными правилами и ссылками на актуальную документацию WM.

## Порядок создания

1. Создать J:\dv\wm-0 и его AGENTS.md.
2. Добавить принадлежащие проекту iq.inc, index.php и корневой test.
3. Создать проектный RM по современной структуре; gss3 используется только как пример состава.
4. Добавить только реально нужные api, css, fonts, i, js, site и wd.
5. Скопировать стандартные resource-модули `r/rb` и `r/lay`: `rb`
   обязателен, `lay` архитектурно опционален, но по умолчанию входит в
   копируемый комплект владельца.
6. Настроить site/iq.inc, site/router.php и нужные site/settings, site/uv без переноса закрытых значений из legacy.
7. Подключить общий J:\dv\wm\web. Локальный web добавлять только для доказанной автономной поставки.
8. Проверить сценарии из 3 test-policy.md.

Полный перечень файлов и границ владения приведён в 3 project-file-set.md. Конкретный контракт wm-0 приведён в 3 wm-0.md.
