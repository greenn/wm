Legacy web

В старых проектах версия общего web указывается комментарием в первой строке
`web/web.php`. Это помогает определить совместимость конкретного snapshot, но
не делает старый web текущим каноном.

Текущая отдельно подтверждённая версия общего `web` — `19.2.11`; версия WM
ведётся независимо. Не менять одну вслед за другой автоматически.

При анализе legacy:

1. прочитать только первую строку и нужные entry points;
2. определить PHP/site version и фактическую цепочку connectors;
3. не копировать v1 pages, Vue 2 или старый RM/API в новый проект;
4. не обновлять старый код попутно;
5. документировать расхождения отдельно.
