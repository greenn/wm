# Экосистема

J:\dv\wm — база фреймворка: общий web, PHP-контракты, resource-модули, бланки, man, aidocs и правила.

J:\dv\wm-0 — первый новый самостоятельный проект: собственные AGENTS.md, iq.inc, index.php, test, проектный RM и прикладные ресурсы.

Dot-projects внутри J:\dv\wm — исторические примеры. Они доступны для точечного чтения, но не входят в baseline-коммит и не являются источником канона.

## Связи

- Новый проект подключает общий J:\dv\wm\web.
- Проект регистрирует site и свой RM через IQ.
- PHP router обрабатывает прямой HTTP-запрос и initial render.
- vue-router Vue 3 может продолжать навигацию в браузере, но сервер обязан корректно отдавать entry point и обрабатывать прямые URI.
- man остаётся центральной human-facing документацией WM; aidocs содержит agent-facing contracts.

Локальная копия web нужна только автономной/внешней поставке. Любое такое дублирование должно быть явно обосновано.
