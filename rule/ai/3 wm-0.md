# Контракт нового проекта wm-0

Первый новый project создаётся в соседнем каталоге `J:\dv\wm-0`.

Минимальное project-owned ядро:

```text
J:\dv\wm-0\
├── AGENTS.md
├── iq.inc
├── index.php
├── test/
└── <project-rm>/             # для первого примера можно использовать gss3
    ├── iq.inc
    ├── pages/
    ├── router/
    └── r/
```

Стандартно копируемая resource-база:

```text
r/
├── rb/
└── lay/
```

`rb` обязателен; `lay` архитектурно необязателен, но входит в стандартный
набор владельца. По реальной потребности проект получает `api`, `css`,
`fonts`, `i`, `js`, `site`, `wd`. Внутри `site` предусматриваются
`settings` и канонический `uv`:

```text
site/
├── iq.inc
├── router.php
├── settings/
└── uv/
```

Режим `web` выбирается явно:

1. local — project содержит `web`, connector `site/web/web[self].inc`;
2. centralized — project не копирует `web`, а host-specific
   `site/settings/settings[<domain>].inc` подключает общий `J:\dv\wm\web`
   через проверенную connector-цепочку.

`man` не копируется: общая human-документация остаётся в WM. Никакие settings
values, product JSON или legacy projects не переносятся.

До признания проекта рабочим проверяются bootstrap, root/index, обычная page,
404, `is-mod`, project handler, API, `rb`/`lay`, project RM templates,
assets/`qv()`, images, `wd` и прямой URL client route.
