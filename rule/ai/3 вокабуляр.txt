# Вокабуляр

- WM — базовый фреймворк и общая ресурсная база J:\dv\wm.
- Проект — отдельное приложение поверх WM со своими iq.inc, index.php, test и проектным RM.
- Dot-project — исторический проект в каталоге с именем, начинающимся с точки. Это читаемый пример, но не часть коммита.
- Бланк — копируемый стартовый шаблон; не гарантированно рабочий проект.
- r — ресурсный слой и механизм работы с ресурсами; named RM может физически
  находиться и вне каталога `r`.
- RM, resource module — именованный ресурсный модуль с коротким внешним API.
- rb — обязательный базовый RM.
- lay — RM компоновки. Он может не вызываться проектом напрямую, но переносится, когда от него зависят шаблоны или другие RM.
- site environment — host/settings/pages/router/uv через `iqSite`.
- site RM — отдельный базовый named RM сайта; не смешивать с функцией
  `site()`, возвращающей IQ environment.
- Компонент — подкаталог RM, подключаемый через собственный .class.inc.
- Шаблон — представление или набор представлений внутри компонента/RM.
- IQ — точка инициализации и регистрации проекта/сайта.
- Library connector — соединитель общей библиотеки.
- RM connector — соединитель конкретного ресурсного модуля. IQ, library connector и RM connector не взаимозаменяемы.
- Page — PHP-описание страницы в canonical pages v2.
- URI — разобранный адрес запроса.
- PID — историческое имя контекста/идентификатора страницы; не следует считать синонимом URI без адаптера.
- PHP router — серверный маршрутизатор: выбирает страницу, данные и начальный HTML.
- vue-router — клиентский маршрутизатор Vue 3: управляет переходами после загрузки SPA. Он не заменяет серверный entry point и fallback.
- man — документация для человека.
- aidocs — точная документация для агента/Codex.
- sug — последовательные предложения по улучшению, требующие одобрения владельца.
- legacy — историческая реализация, пригодная как справка, но не как канон.
- test — корневой каталог URL-доступных тестов и демонстраций проекта.
