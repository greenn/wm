# Версионность WM

## 1. Область действия

WM и общий `web` имеют отдельные версии.

- Официальная текущая версия WM всегда читается из `VERSION.json`.
- Исходная baseline этой серии изменений: `20.0.1`.
- Текущая отдельно зафиксированная версия `web`: `19.2.11`.

Изменение WM не должно автоматически менять версию `web`, и наоборот.

## 2. Формат

WM использует SemVer-подобный формат:

```text
MAJOR.MINOR.PATCH
```

- `MAJOR` и `MINOR` меняются только по явному решению владельца или отдельному
  согласованному плану выпуска.
- `PATCH` увеличивается на один для каждого атомарного commit/подзадачи.

Старая схема, где `MINOR` автоматически означал активный календарный день, для
WM 20 не применяется без нового прямого решения владельца.

## 3. Атомарная подзадача

Один commit должен содержать один связный, самостоятельно объяснимый результат.
Если пользовательский запрос разумно разбит на три commits, PATCH повышается три
раза.

Пример:

```text
20.0.1 -> 20.0.2 -> 20.0.3 -> 20.0.4
```

Количество изменённых файлов внутри одного атомарного commit не влияет на число
версий.

## 4. Когда версия не меняется

Версия не повышается при анализе, обсуждении, чтении, диагностике или проверке,
если repository files фактически не изменялись и commit не создавался.

Не создавать пустой commit только ради номера версии.

## 5. Порядок обновления

Перед каждым commit, изменяющим WM:

1. определить следующий PATCH от текущей версии;
2. обновить официальный version metadata WM;
3. синхронно обновить отображаемую версию в UI, API, CLI, HTML или логах, если
   она там зафиксирована;
4. проверить, что commit не содержит несвязанных пользовательских изменений;
5. использовать новую версию в сообщении commit и итоговом отчёте.

Version metadata и следующий PATCH нельзя угадывать по этому документу: перед
изменением всегда читать `VERSION.json`. Если файл версии недоступен или
противоречит этим правилам, остановиться и уточнить у владельца.

## 6. Дата

Если version metadata хранит дату, использовать локальную календарную дату
пользователя (`Europe/Moscow` для текущего WM), а не UTC. Дата не управляет
автоматически `MINOR`.
