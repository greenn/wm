# Dot-projects

Каталоги `.vmk4`, `.ash`, `.gss1`, `.ripr`, `.kp`, `.kp2`, `.zo`,
`.tosno` и другие dot-projects — внешние project snapshots внутри WM.

Политика:

- разрешено точечно читать их для анализа конкретного contract;
- они исключены из commits WM;
- current v2 и решения владельца выше по приоритету;
- один подходящий пример лучше массового обхода всех проектов;
- product/catalog JSON учитываются по именам/количеству, содержимое не читается
  без отдельной необходимости;
- settings, tokens, credentials и персональные данные не выводятся;
- найденные проблемы документируются, но не исправляются попутно.

`.blank` и `.blank2` — отдельное исключение: это коммитируемые структурные
заготовки, а не внешние dot-projects.
