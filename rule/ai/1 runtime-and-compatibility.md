# Runtime и совместимость

## Сервер

- Целевая версия для нового кода WM — PHP 7.2.
- `short_open_tag=On` обязателен.
- Новый project PHP использует короткие теги `<?` и короткий вывод `<?=`.
- Нельзя использовать синтаксис и стандартные функции, появившиеся после PHP
  7.2, без отдельного polyfill и явного решения.
- Проверка PHP выполняется тем же runtime или совместимым PHP 7.2 с включёнными
  short tags.

Существующий long-tag или legacy-код не переписывается массово. Правило коротких
тегов относится к новому коду данного framework.

## Браузер

- Новый Vue-код использует Vue 3.
- Vue 2 сохраняется только для legacy и не копируется как основа нового
  приложения.
- jQuery и Lodash допустимы там, где они уже являются частью решения.
- Node, npm, TypeScript и обязательная frontend-сборка не добавляются без
  прямой необходимости и согласования.
- `console.log` включён по умолчанию для значимых этапов и ошибок; секреты и
  большие данные в него не выводятся.

## Маршрутизация

PHP-router остаётся серверной точкой истины о том, какую страницу и начальный
HTML отдавать. `vue-router` может управлять переходами внутри приложения,
каталога или корзины, включая историю назад/вперёд, но прямой URL и reload
должны снова корректно пройти через PHP-router.

## Совместимость изменений

1. Не ломать существующие вызовы без отдельной миграции.
2. Не переносить Vue 2 или v1 page/router в новый код.
3. Проверять current v2, затем точного потребителя.
4. Legacy сохранять и документировать отдельно.
5. Новую зависимость проверять на PHP 7.2 и используемые браузеры до включения.
