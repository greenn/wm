# API

API соединяет frontend, site/RM и административную часть. Site RM может обращаться к БД напрямую либо использовать внутренний admin API — выбирается более ясная граница ответственности для конкретного проекта.

## Контракт

- Публичный endpoint должен иметь явный HTTP-метод, формат входа/выхода и коды ошибок.
- Авторизация и проверка прав выполняются на сервере.
- Клиентские проверки не считаются защитой.
- Ответы не должны содержать credentials, внутренние пути и необработанные исключения.
- Новые реализации ориентируются на PHP 7.2 и действующий v2 API.

Административная точка входа по умолчанию физическая: /admin/index.php. Серверный PHP router отвечает за HTTP и данные; vue-router Vue 3 отвечает только за клиентские переходы внутри уже загруженного интерфейса.

Исторические admin/kot/ap варианты используются как справка, а не копируются автоматически.
