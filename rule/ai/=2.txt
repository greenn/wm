Этап 2 — AGENTS.md и aidocs

Цель

Создать в корне WM короткий agent-first `AGENTS.md` и структурированную карту
`aidocs`, достаточную для безопасной работы Codex с текущим фреймворком.

AGENTS.md

`AGENTS.md` должен быть коротким и содержать только правила, которые нужны почти
в каждой задаче:

- приоритет владельца и `rule/ai`;
- PHP 7.2, `short_open_tag=On`, только короткие PHP-теги;
- v2 и Vue 3 для нового кода, Vue 2 как legacy;
- naming, минимальный diff и прагматичный DRY;
- правила RM connector, IQ и library connector;
- exclusions, секреты и запрет массового чтения контентных JSON;
- политика документации, версии и Git;
- ссылки на подробные разделы `aidocs`.

aidocs

`aidocs` — внутренняя документация для агента, не копия пользовательского `man`.
Она должна содержать короткие карты и точные точки входа:

- устройство WM, `web`, IQ и project/site environments;
- resource layer, RM, `rb`, `lay`, `site`, `admin` и connectors;
- templates, API router, старые и новые pages, page router;
- asset pipeline: CSS, JS, fonts, images, `_i`, `uv`, `wd`, `mqr`;
- `web/lib` и `_lib`;
- PHP-функции из `web/php` с файлами, сигнатурами, вызываемыми подфункциями и
  ключевыми call chains;
- `.htaccess`, разобранные по смысловым секциям и фактическим rewrite chains;
- blank-заготовки, тесты, legacy и project overlays;
- различие human docs `man/wm`, agent docs `aidocs` и proposals `man/sug`.

Метод

1. Инвентаризировать код без чтения исключённых данных и секретов.
2. Проверять определения по фактическим вызовам, а не только по именам.
3. Для каждой сущности указывать назначение, entry point, обязательные файлы,
   типичный вызов, зависимости, v2/legacy status и известные риски.
4. Не копировать большие фрагменты исходников; давать точные пути и короткие
   примеры.
5. Предложения по skills, hooks, MCP и subagents оформить отдельно. Не
   устанавливать и не включать их без approval владельца.

Критерий готовности: новый агент сначала читает `AGENTS.md`, затем переходит по
ссылкам в `aidocs` и может безопасно найти нужный код без полного обхода WM.
