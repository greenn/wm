в директории man (отвечающая за нашу Developer Docs Documentation Site)
лежат следующие под-директории

wm - основная дока по фреймворку

sug - система твоих предложенией. она описана, соответственно в 3 sug.txt

site - дока по текущему сайту, страницы, подключённые ресурсные модели.

admin - дока по админке с названием admin. Также может называться и admin2 или kot (есть у меня админка с таким названием)

rm/site дока по ресурсному модулю site. показывает какие компоненты, ест ли там api, какие темплейты и их строение

rm/rb - дока по базовому ресурсному модулю

wm/php - перечень всех php функций и подфункций
