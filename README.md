# WM

WM `20.0.1` — общий PHP-фреймворк и ресурсная база для сайтов и приложений.

- Runtime: PHP 7.2 с обязательным `short_open_tag=On`.
- Новый frontend-код: Vue 3; Vue 2 считается legacy.
- `web/` содержит общее PHP-ядро и библиотеки.
- `r/` — ресурсный слой; `rb` и `lay` — именованные ресурсные модули.
- `.blank/` и `.blank2/` — коммитируемые заготовки проектов.
- `rule/dd/` — входные материалы владельца; `rule/ai/` — нормализованные задания для Codex.

Внешние dot-проекты используются как примеры, но не входят в Git-репозиторий WM.
